Маршрут — порядок категорій під конкретну позицію.

- **Senior .NET backend:** C# та .NET → ASP.NET Core → Бази даних → Доступ і безпека → Інтеграції та архітектура → Якість і постачання → Основа.
- **Fullstack .NET:** той самий маршрут плюс Фронтенд.
- **Legacy і модернізація:** Delphi → Бази даних → Інтеграції та архітектура.
