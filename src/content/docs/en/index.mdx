## How to use

<CardGrid>
  <Card title="Answer level" icon="setting">
    Above the questions is a Junior / Middle / Senior / All switch. Every question has a short and an in-depth answer for each level. Your choice is remembered.
  </Card>
  <Card title="Flashcards" icon="approve-check">
    Flashcards mode hides the answers: answer yourself first, then reveal.
  </Card>
  <Card title="Terms" icon="information">
    Words with a dotted underline open a definition: on the right on desktop, at the bottom on a phone. From there — Google, docs, Wikipedia.
  </Card>
  <Card title="Self-check" icon="star">
    "Know it / Shaky / Don't know" under every question. Progress is kept in this browser.
  </Card>
</CardGrid>

## Tracks

A track is an order of categories for a specific role.

- **Senior .NET backend:** C# & .NET → ASP.NET Core → Databases → Access and security → Integrations and architecture → Quality and delivery → Fundamentals.
- **Fullstack .NET:** the same track plus Front end.
- **Legacy and modernization:** Delphi → Databases → Integrations and architecture.
