## Маршруты

Маршрут — порядок категорий под конкретную позицию.

- **Senior .NET backend:** C# и .NET → ASP.NET Core → Базы данных → Доступ и безопасность → Интеграции и архитектура → Качество и поставка → Основа.
- **Fullstack .NET:** тот же маршрут плюс Фронтенд.
- **Legacy и модернизация:** Delphi → Базы данных → Интеграции и архитектура.
